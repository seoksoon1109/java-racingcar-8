# java-racingcar-precourse

## 🚗 구현할 기능 목록

### 1️⃣ 입력 및 검증 (InputView, InputValidator)
- [x] 사용자로부터 자동차 이름을 입력받는다. (쉼표로 구분)
- [x] 사용자로부터 시도 횟수를 입력받는다.
- [x] 자동차 이름은 1~5자 이내, 공백 불가, 중복 불가해야 한다.
- [x] 시도 횟수는 숫자이며 1 이상이어야 한다.
- [x] 잘못된 입력이 들어오면 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

---

### 2️⃣ 자동차 전진 및 이동 로직 (Car, Cars)
- [x] 자동차는 이름과 현재 위치를 가진다.
- [x] 0~9 사이의 랜덤 값 중 4 이상이면 전진한다.
- [x] 여러 대의 자동차를 관리하며, 모든 자동차를 한 번씩 이동시킨다.
- [x] 각 자동차의 위치를 "-" 문자열로 표현한다.

---

### 3️⃣ 우승자 판별 (WinnerCalculator)
- [ ] 가장 멀리 이동한 자동차(들)를 우승자로 선정한다.
- [ ] 공동 우승자가 있을 경우 쉼표(,)로 구분하여 출력한다.

---

### 4️⃣ 결과 출력 (OutputView)
- [ ] 각 시도별 실행 결과를 출력한다.
